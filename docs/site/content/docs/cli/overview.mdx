The OCC CLI is the `occ` command-line interface for scripting a running OCC editor from any shell. Use it to create and inspect worktrees, drive agent terminals, open files and diffs, automate the built-in browser, run scheduled automations, share HTML/Markdown artifacts, and control OCC-native tools from scripts or AI agents.

It ships with the desktop app; register it under [Settings → General → OCC CLI](/docs/settings). On Linux the command is `occ-ide`, because GNOME OCC's screen reader already owns `/usr/bin/occ` — see [Install → Linux](/docs/install#linux).

Agents can install the matching OCC CLI skill with:

```bash
npx skills add https://github.com/stablyai/occ --skill occ-cli
# headless / no Settings UI:
occ skills install --skill occ-cli
```

See [Skills registry & MCP](/docs/cli/skills) for every installable OCC skill, including `occ skills install` / `occ skills update`.

## Install & verify

```
command -v occ
occ status --json
```

## Worktree commands

```
occ worktree ps --json
occ worktree create --repo id:<repoId> --name my-task --issue 123 --json
occ worktree create --repo id:<repoId> --name review-pr-123 --pr 123 --json
occ worktree current --json
occ worktree set --worktree active --comment "reproduced bug" --json
occ worktree set --worktree active --gitlab-issue 42 --gitlab-mr 77 --json
occ worktree set --worktree active --pr null --json
occ worktree rm --worktree id:<id> --force --json
```

For selectors, setup flags, parent/child worktrees, and the broader command map, see [OCC CLI reference](/docs/cli/reference).

## Terminal commands

```
occ terminal list --json
occ terminal read --json
occ terminal send --text "continue" --enter --json
occ terminal wait --for tui-idle --timeout-ms 30000 --json
occ terminal create --worktree path:/projects/app --command "npm test" --json
occ terminal split --direction vertical --command "npm run dev" --json
```

For tracked multi-agent work, use [Orchestration](/docs/cli/orchestration) instead of plain terminal prompts.

## File commands

Open files and diffs as tabs in their OCC worktree from a shell. They open without changing what you are looking at; add `--focus` to be brought to the file:

```
occ file open src/App.tsx
occ file diff src/App.tsx --staged
occ file open-changed --mode both
```

Use `--worktree <selector>` when the shell's current directory is not inside the target worktree.

## Browser profiles

Browser profiles isolate tab session state, so a script or agent can test with different cookies, local storage, and logged-in identities. The CLI exposes profile commands under `occ tab profile`; start with `occ tab profile list --json`, then use `create`, `set`, `clone`, or `use-default` as needed.

## Scheduled automations

Use `occ automations` to create, inspect, run, and remove scheduled OCC tasks from a shell. Start with [Scheduled automations](/docs/cli/automations) when you want a recurring prompt to run against a repo or an existing worktree.

## Artifacts

Share HTML or Markdown as public view links through the signed-in OCC account (`occ artifacts share|update|list|delete`). Publishing is **opt-in** under Settings → Artifacts. Command details: [CLI reference → Artifacts](/docs/cli/reference#artifacts).

## Browser automation

The CLI also drives the built-in browser with a snapshot-interact-re-snapshot loop:

```
occ goto --url https://example.com --json
occ snapshot --json     # returns refs like @e1, @e3
occ click --element @e3 --json
occ fill --element @e1 --value "user@example.com" --json
occ screenshot --json
```

For responsive browser checks, switch the active tab to a named device profile:

```
occ set device --name "iPhone 12" --json
occ screenshot --json
```

## Mobile emulator

The CLI can also drive an iOS Simulator through OCC's mobile emulator bridge. It is scoped to the active worktree, so agents and scripts can attach a simulator from `occ emulator list`, tap normalized coordinates, type text, send gestures, rotate the device, and shut it down without leaving OCC.

```
occ emulator list --json
occ emulator attach "<device-name-or-udid>" --json
occ emulator tap 0.5 0.7 --json
occ emulator type "hello" --json
occ emulator gesture '[{"type":"begin","x":0.5,"y":0.8},{"type":"move","x":0.5,"y":0.4},{"type":"end","x":0.5,"y":0.2}]' --json
occ emulator rotate landscape_left --json
occ emulator kill --json
```

Use `--worktree <selector>`, `--device <udid-or-name>`, or `--emulator <id>` when a script needs an explicit target.
